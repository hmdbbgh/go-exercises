# Leap — README

This folder contains an idiomatic implementation of the Exercism **Leap** exercise.

## Files Included

### ✔ `solution.go`
Compact and idiomatic implementation using a boolean expression.

### ✔ `alternative.go`
Readable version using explicit if/else branching.

### ✔ `notes.md`
Explains leap-year rules, implementation styles, performance, and benchmarks.

### ✔ `leap_test.go`
Full test suite including benchmark.

## Running Tests
```
go test ./...
```

## Running Benchmarks
```
go test -bench=.
```
