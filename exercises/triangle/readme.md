# Triangle — README

This folder contains two implementations of the Exercism **Triangle** exercise:

- `solution.go` — idiomatic implementation  
- `alternative.go` — epsilon‑based floating‑point version  
- `notes.md` — detailed explanation of the algorithm, enums, `iota`, and design choices  
- `triangle_test.go` — complete tests  

Run tests:

```
go test ./...
```
